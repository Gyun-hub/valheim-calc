## 요약

| 항목 | 결론 |
|---|---|

## 1. 반드시 지킬 것

### 1-1. 이미지는 직접 제작
**현재 상태**: `data/*.json`의 `image_source_url`은 원본 위키 이미지 URL만 기록.
파일 다운로드 · 재배포 **하지 않음**. `image_local_path`는 전부 `null`.

**서비스 전 필수 조치**
- [ ] 아이콘 전량 직접 제작 (또는 직접 플레이하며 찍은 스크린샷으로 대체)
- [ ] `image_source_url`은 참고용으로만 사용, 프로덕션 빌드에 노출 금지
- [ ] 게임 로고 · 공식 마케팅 아트워크 사용 금지

**대안 (이미지 부담 완화)**
- MVP는 텍스트 · 수치 중심으로 가고 아이콘 의존도 낮추기
- 오픈소스 게임 아이콘팩 스타일로 재해석해서 그리기
- 아이템 800종+ 전부 그릴 필요 없음. 자주 쓰는 것부터

### 1-2. 텍스트 그대로 복사 금지
Fandom 위키는 **CC BY-SA 3.0**. 텍스트를 그대로 가져오면 출처 표시 + 동일 라이선스 재배포 의무 발생.
나무위키도 마찬가지.

→ **수치만 참고하고 설명문은 자체 작성.** 이게 가장 깔끔함.

### 1-3. `/about` 페이지 필수 고지
```
이 사이트는 비공식 팬 프로젝트입니다.
Iron Gate AB 및 Coffee Stain Publishing과 아무런 관련이 없습니다.
Valheim은 Iron Gate AB의 상표입니다.
```

### 1-4. 확률 데이터 신뢰도 표기
`drop_tables[].confidence` 필드를 UI에 노출.
현재 55개 전부 `datamined`(게임 파일 추출)이지만, Iron Gate가 공식 발표한 수치는 아님.

→ "커뮤니티 데이터마이닝 기반 추정치" 명시.

## 2. 애드센스 관련

**심사 전 체크리스트**
- [ ] 저작권 소지 이미지 전량 제거 확인
- [ ] `/about` 고지 페이지 존재
- [ ] 개인정보처리방침 페이지 (애드센스 요구사항)
- [ ] 콘텐츠 양 충분한지 (도감 페이지가 100+ 확보해줌)

**주의**: 저작권 침해 소지 이미지가 많으면 애드센스 승인 자체가 반려될 수 있음.
1-1을 지키는 게 법적 이유뿐 아니라 수익화 관점에서도 중요.

## 3. 조사로 확인된 사실

### Iron Gate EULA 주요 조항
- **4.1조 (허용)**: 스크린샷 · 플레이 영상 SNS 공유, 유튜브/트위치 광고 수익화 명시적 허용
- **5.2.3조**: 게임 수정 · 파생물 생성 금지
- **5.2.4조**: 사전 서면 동의 없는 공적 · 상업적 이용 금지
- **5.2.5조**: 리버스 엔지니어링 금지

→ 에셋 파일 추출 후 웹사이트 재게시는 **4.1 허용 목록에 없음**. 회색~금지 영역.

### 집행 사례
- Iron Gate가 팬 위키 · 계산기 · 유튜브에 DMCA/C&D 보낸 사례 **조사 범위 내 전무**
- 공식 사이트(valheimgame.com) 푸터가 Fandom 위키를 직접 링크 — Fandom은 광고 수익 플랫폼
- valculator.io, valheim.tools 등 계산기 사이트 장기간 무탈 운영

### 정책 문서
- EULA 3.6조가 "Content Usage Guidelines" 문서의 존재를 언급하나, **실제 공개 문서를 찾지 못함**
- Riot("Legal Jibber Jabber") · Mojang("Usage Guidelines") 같은 명문화된 공개 가이드라인 없음
- 소규모 스튜디오라 정책 투명성은 낮고, 실무는 관대한 상태로 추정

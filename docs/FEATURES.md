## 1. 포지셔닝

**한 줄 정의**: 한국어로 된 발헤임 계산기 모음 + 데이터베이스

**경쟁 상황**
- 영어권: valheim.tools, Valculator, XGamingServer 등 이미 포화
- 한국어권: 나무위키 텍스트 공략만 존재. **인터랙티브 계산기 전무**
- 나무위키와 안 겹치는 지점 = "입력하면 계산해주는 도구". 위키는 읽는 것, 우리는 쓰는 것

**차별점 3개**
1. 한국어 (언어 자체가 진입장벽 역할)
2. 계산기 UX (나무위키는 표만 있음)
3. 영어권에도 없는 툴 (길들이기, 멀티 스케일링, 드롭률 시뮬레이터)

## 3. 페이지별 기능 명세

### 3-1. `/` 홈
| 기능 | 설명 | 우선도 |
|---|---|---|
| 계산기 카드 그리드 | 8개 계산기 진입점, 아이콘+한줄설명 | 필수 |
| 통합 검색 | 아이템/몬스터/음식 이름으로 검색 → 해당 DB 상세로 이동 | 필수 |
| 진행도 트래커 | 보스 7종 체크리스트 (localStorage 저장) | 선택 |
| Deep North 배너 | 9/9 출시 대비 신규 콘텐츠 유도 | 시즌 |

### 3-2. `/calc/build` 제작·건축 자원 계산기 ★최우선
| 기능 | 설명 | 데이터 |
|---|---|---|
| 아이템 선택 + 수량 입력 | 만들 아이템 여러 개 담기 (장바구니 방식) | `recipes` 49개 |
| 총 재료 자동 합산 | 중복 재료 합쳐서 최종 필요량 출력 | ready |
| 재귀 계산 | 청동 → 구리+주석 까지 역산 (중간재 자동 전개) | ready |
| 필요 작업대 표시 | 대장간 Lv2 등 요구 스테이션·레벨 | ready |
| 보유량 차감 | 현재 갖고 있는 재료 입력 → 부족분만 표시 | ready |
| 건축 자재 계산 | 목재벽 100개 = 나무 몇 개 | `building_pieces` 12개 |
| 결과 공유 | URL에 상태 인코딩 → 링크 공유 | - |

### 3-3. `/calc/food` 음식 조합 최적화 ★수요 높음
| 기능 | 설명 | 데이터 |
|---|---|---|
| 음식 3슬롯 선택 | 발헤임은 동시 3종까지 섭취 | `food` 19개 |
| 합산 스탯 표시 | 체력/스태미나/에이트르 총합 + 회복력 | ready |
| 최적 조합 추천 | 목적별(탱커/스태미나/마법) 자동 추천 | ready |
| 보유 재료 기반 필터 | 지금 가진 재료로 만들 수 있는 것만 | ready |
| 지속시간 타이머 | 각 음식 남은 시간 시각화 | ready |

### 3-4. `/calc/drop` 드롭률 확률 시뮬레이터 ☆영어권에도 없음

## 6. 법적 준수 사항

→ [LEGAL.md](LEGAL.md) 참고.

기능 구현 시 직접 영향 주는 것만:
1. `/about` 페이지에 비공식 고지 — **필수 페이지**
2. 아이콘은 직접 제작한 것만 사용. `image_source_url`은 참고용, 프로덕션 노출 금지
3. 도감 설명문은 자체 작성 (위키 텍스트 복사 금지)
4. 드롭률 UI에 `confidence` 필드 노출 (데이터 출처 표기)
5. 개인정보처리방침 페이지 (애드센스 요구사항)

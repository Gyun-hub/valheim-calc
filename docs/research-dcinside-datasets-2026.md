## 종합 평가

- 유효한 후보 **7개**를 찾음 (아이템/무기 1건, 보스 1건, 몬스터+아이템 1건, 바이옴/편안함 시스템 1건, 진행가이드+음식 1건, 모드 카탈로그 1건, 잿가루지대 종합팁 1건).
- 전반적으로 게시일이 2021~2024년 사이로 분산돼 있어, 최신 업데이트(특히 잿가루지대/Ashlands 정식 출시 이후 밸런스) 반영 여부를 개별 검증해야 함.
- 이미지 첨부형 게시글(후보 1)은 WebFetch로 실제 표 내용을 확인 못했으므로, 사용자가 직접 이미지를 열람해 판독하거나 스크린샷을 공유해줘야 실질적 활용 가능.
- 검색엔진 인덱싱이 갤러리 특성상 들쭉날쭉해서, 오래된 글(2021~2022년)일수록 검색 노출이 잘 되고 최신 글은 상대적으로 덜 걸리는 경향 관찰됨. 추가 조사 시 갤러리 자체 검색(디시인사이드 내부 검색)을 활용하면 더 많은 후보를 찾을 가능성 있음.

## 2차 조사 (내부검색)

조사일: 2026-08-02 (같은 날 이어서 진행)
조사 방법: 디시인사이드 갤러리 자체 검색을 WebFetch로 직접 호출. 로그인·캡차 없이 접근 가능했음.

### 기술 메모: 내부 검색 URL 패턴

- 확인된 동작 URL: `https://gall.dcinside.com/mgallery/board/lists/?id=valheim&s_type=search_subject_memo&s_keyword=<URL인코딩된 키워드>&search_pos=0`
- `s_type=search_subject_memo`(제목+내용)로 정상 검색됨. 로그인/캡차 차단 없음.
- **관찰된 특이 동작**: 키워드가 단일 단어(예: "테이밍", "번식", "에이트르", "던전", "빌드", "건축", "위습", "잿가루지대")일 때는 실제 매칭 결과가 반환됨. 반면 띄어쓰기가 들어간 2어절 이상 키워드(예: "채집 팁", "농사 정리", "항해 팁", "바람 방향", "마법 빌드", "던전 정리", "룬 문자", "위습 정리", "빌드 공유", "보물지도" 일부)는 대부분 "검색 결과가 없습니다"로 반환됨 — 디시 자체 검색이 정확 부분 문자열(phrase substring) 매칭이라, 띄어쓰기까지 정확히 일치하는 게시글이 드물기 때문으로 추정. **후속 조사 시 단어를 붙여쓰기하거나 한 단어씩 나눠서 검색하는 편이 결과를 더 잘 찾음.**
- WebFetch가 페이지를 요약할 때 "검색 결과가 없습니다" 안내문과 실제 검색 결과 목록이 같은 페이지에 섞여 있어("게시물은 1만개 단위로 검색됩니다" 등 안내문 + 결과 테이블), 요약 모델이 이를 혼동해 실제로는 결과가 있는데도 "검색 안 됨"으로 잘못 보고하는 경우가 있었음(예: "테이밍", "번식" 검색은 실제로는 정상 매칭 결과였음). 사람이 재검증 시 이 점 유의.

- 교차검증 필요 여부: **필요하지만 우선순위 낮음**. 편법성 정보라 `data/creatures.json`의 정식 필드(취약점/드롭 등)에는 직접 매핑하기 어려움. 참고만 하고 데이터셋 채택은 보류 권장.

### 대상: 전체 바이옴 몬스터 (목초지~안개지대) 속성 저항/취약표

### 대상: 전투 메커니즘(가드/블로킹) — 보스 다수에 적용 가능한 공통 팁

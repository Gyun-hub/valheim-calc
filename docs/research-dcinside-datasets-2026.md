## 후보 2: 검(Sword) 정보 정리
- URL: https://gall.dcinside.com/mgallery/board/view/?id=valheim&no=12206
- 게시일: 2021-03-14
- 요약: 청동검·철검·은검·흑철검·뒤른빈(치트 전용)까지 모든 근접 검 무기를 표로 정리. 각 무기별로 필요 대장간 레벨, 제작/강화 재료, 무게·내구성, 공격력(베기/특공/밀쳐내기), 방어력(막기위력/쳐내기)을 항목화. 저자는 "은검이 영혼특공 적용 시 흑철검보다 실전 강함"이라는 해석도 덧붙임.
- 데이터셋 후보 이유: `data/items.json` 무기 항목의 제작 재료·강화 단계·수치 데이터와 겹치는 구조. 다만 2021년 3월 작성으로 이후 밸런스 패치(Mistlands, Ashlands 업데이트 등) 반영 안 됐을 가능성 높음.
- 교차검증 필요 여부: **필수**. 게시 시점이 오래돼 수치가 현재 게임 버전과 다를 수 있음. 반드시 공식 위키/게임 내 수치로 재검증 후 사용.

## 후보 3: 잿가루지대까지 편안함 정리
- URL: https://gall.dcinside.com/mgallery/board/view/?id=valheim&no=39993
- 게시일: 2024-05-06
- 요약: 바이옴별 최대 편안함(comfort) 수치를 정리(목초지 5 / 검은숲 9 / 늪지대 12 / 산 13 / 평원 16 / 안개지대 16 / 잿가루지대 17)하고, 편안함에 기여하는 가구 17종(화로·침대·러그·배너·왕좌·탁자·갑옷 거치대·욕조·용상·용암 랜턴 등)을 나열. "편안함 레벨+7=버프 지속시간", "가구는 종류별 1개만 적용, 10m 이내에서만 효과" 같은 게임 메커니즘 설명 포함.
- 데이터셋 후보 이유: 수치가 명확하고 구조화되어 있어(바이옴별 comfort 상한, 가구 목록) `data/biomes.json` 또는 아이템(가구) 데이터 보강에 참고 가능. "수치만 참고" 규칙에 부합하는 형태.
- 교차검증 필요 여부: **필요**. comfort 상한 수치와 가구 목록은 공식 위키/게임 데이터와 대조 확인 권장. 최신 잿가루지대(Ashlands) 업데이트 반영 여부 확인 필요.

## 후보 4: 잿가루지대 팁 개인적인 정리
- URL: https://gall.dcinside.com/mgallery/board/view/?id=valheim&no=44759
- 게시일: 2024-11-05
- 요약: 잿가루지대 공략 팁 13가지. 광물 운송법(돌 포탈), 불금속 파밍처(요새 약탈), 몬스터 대응(화산매는 첫 스폰만 존재 → 즉시 처치, 위험 시 드베르그 기지로 도피), 추천 음식(체력 105 회복 음식 우선), 추천 보석(근청석/번개, 혈석 비추천), 현무암 폭탄 활용 등. 조회수 30,646 / 추천 6으로 갤러리 내 반응 좋은 편.
- 데이터셋 후보 이유: 몬스터(`data/creatures.json`) 취약점·공략팁, 음식(`data/food.json`) 추천 조합 등 여러 엔티티에 걸친 실전 팁. 조회수가 높아 커뮤니티 검증도 어느 정도 된 편.
- 교차검증 필요 여부: **필요**. "화산매 첫 스폰만 존재" 같은 구체적 게임 메커니즘 주장은 공식 정보로 검증 필요. 개인 경험담 성격의 팁도 섞여 있어 수치화 가능한 부분만 선별해야 함.

## 후보 5: 아낌없이 주는 나무! 어보미네이션 공략
- URL: https://gall.dcinside.com/mgallery/board/view/?id=valheim&no=23149
- 게시일: 2022-02-26
- 요약: 늪지대 미니보스 어보미네이션(Abomination) 공략. 나무 밑동으로 위장하다 인식 거리 진입 시 기상하는 특징, 화염 취약점, 늪지 불 스포너를 이용한 화공 사냥법, 방패+구르기 방어 전투법을 설명. 드롭 아이템(나무, 고대 나무껍질, 찌꺼기, 뿌리, 확률적 트로피)과 뿌리 방어구 세트효과(독저항 투구/관통저항 흉갑, 3세트 시 활 기술 +15)까지 정리.
- 데이터셋 후보 이유: 몬스터 취약점·드롭 데이터(`data/creatures.json`)와 방어구 세트효과(`data/items.json`) 둘 다에 걸치는 구체적 정보. 취약점·드롭·세트효과처럼 수치/사실 기반 정보 위주라 "수치만 참고" 규칙에 맞게 재가공하기 쉬움.
- 교차검증 필요 여부: **필요**. 2022년 2월 작성으로 다소 오래됨. 드롭 목록·세트효과 수치는 공식 데이터로 재확인 권장.

## 후보 6: 발헤임 공략 (지역별 순서대로)
- URL: https://gall.dcinside.com/mgallery/board/view/?id=valheim&no=25585
- 게시일: 2022-10-18
- 요약: 목초지→검은숲→늪→산→평원→안개지대(미완성) 순서의 진행 가이드. 스턴(허우적거림) 상태에서 3배 이상 대미지 들어가는 전투 메커니즘, 방패 패링·스태미나 관리 팁, 보스별 약점, 그리고 지역별 "추천 음식 3종 세트" 조합을 제시.
- 데이터셋 후보 이유: 바이옴 진행 순서(`data/biomes.json`)와 음식 조합(`data/food.json`) 추천이 구조화돼 있어, 기존에 확보한 음식 조합표 자료와 상호 보완 가능. 다만 안개지대 이후(안개지대도 미완성, 잿가루지대 없음)라 최신 콘텐츠는 누락.
- 교차검증 필요 여부: **필요**. 스턴 대미지 배율(3배) 같은 구체적 수치는 공식 정보로 검증 필요. 2022년 10월 작성이라 최신 바이옴(잿가루지대) 반영 안 됨.

## 종합 평가

- 유효한 후보 **7개**를 찾음 (아이템/무기 1건, 보스 1건, 몬스터+아이템 1건, 바이옴/편안함 시스템 1건, 진행가이드+음식 1건, 모드 카탈로그 1건, 잿가루지대 종합팁 1건).
- 전반적으로 게시일이 2021~2024년 사이로 분산돼 있어, 최신 업데이트(특히 잿가루지대/Ashlands 정식 출시 이후 밸런스) 반영 여부를 개별 검증해야 함.
- 이미지 첨부형 게시글(후보 1)은 WebFetch로 실제 표 내용을 확인 못했으므로, 사용자가 직접 이미지를 열람해 판독하거나 스크린샷을 공유해줘야 실질적 활용 가능.
- 검색엔진 인덱싱이 갤러리 특성상 들쭉날쭉해서, 오래된 글(2021~2022년)일수록 검색 노출이 잘 되고 최신 글은 상대적으로 덜 걸리는 경향 관찰됨. 추가 조사 시 갤러리 자체 검색(디시인사이드 내부 검색)을 활용하면 더 많은 후보를 찾을 가능성 있음.
